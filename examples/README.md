# Examples

These source-controlled examples mirror the three integration modes shown on
the landing page:

- [`headless-vanilla.js`](./headless-vanilla.js) — custom controls with the
  framework-independent controller
- [`toolbar-vanilla.js`](./toolbar-vanilla.js) — the standard embedded toolbar
- [`PlaybackControls.tsx`](./PlaybackControls.tsx) — a custom React component
  built with the headless hook

Copy the relevant file into an app that has `slowmo` installed.
